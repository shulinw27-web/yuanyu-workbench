# 产品需求、实施计划与工作清单

日期：2026-11-07（2026-11-13核对）。状态：M0—M3完成；M4继续逐项推进；M5个人免费版与企业联系入口的可本地验证部分完成，W23待公网验收；M6按A→B→C推进，A/B阶段子项及C阶段可本机验证子项已合成回归通过，账号撤权端到端与真实效果对照未开始，父项待整体验收。真实环境与未开发项不混记完成。另含本机合成演示测试账号预填、默认滚动条隐藏、取消竞态修复及记忆撤权/外发授权端到端回归等体验与回归改动，不新增真实环境验收结论。证据见[测试报告](TEST_REPORT.md)。

## 1. 定位与决策

元域面向企业中的个人，帮助其完成本人权限内、重复发生的跨系统工作，并生成可核对交付物。通过自然语言说明、人工示范和既有成品逐步建立个人技能。正式产品采用一个工作台入口；取消独立语义层产品，不将企业世界模型作为使用前提。

选择新项目而非裁剪旧分支：旧项目未提交改动保留，旧模块和安装均不改；独立项目 `yuanyu-workbench`。本地版本管理采用 `personal` 与 `enterprise` 两个独立历史分支，详见[版本说明](EDITIONS.md)。禁止将旧项目整库、凭据、运行数据或历史文档搬入新项目。

## 3. 首轮有限场景

采购月度资料整理：Mock采购与Mock仓储两个不同本机站点，员工用各自账号登录，选月份，按采购单号关联已审核订单与入库记录。输出已入库/部分/未入库的明细、金额及来源说明。2026-10和2026-09有不同合成数据，验证参数复用。缺少入库不能推断丢失或业务根因；产物是业务草稿，不是财务结账或正式财报。

首轮自然语言入口采用明确的预设任务识别器，**不把关键词识别当作LLM理解验收**。网页自动化采用固定、可核对配方，不声称适配任意网站。首轮不填写/提交真实采购单，不审批、不付款、不外发文件。

## 4. 轻量架构

原生HTML/CSS/JS工作台 → 受限IPC → 单个Electron主进程 → 本机凭据库/工作流存储/任务执行器 → 受控浏览器与文件工具。浏览器业务页面独立会话、无Node/preload/IPC，不能从页面指令调用本机工具。站点/工具/模板由主进程白名单限定，不接受任意JS和shell命令。

本机加密文件使用操作系统保护；Windows DPAPI保护静态存储及其他系统用户，不能宣称抵御同用户恶意程序。默认无云同步。凭据与浏览器会话分开管理；分享的模板不携带任何账号授权。

共享分为个人草稿、试运行通过、公司发布固定版本、接收者添加到个人流程；新版不静默覆盖。首轮Mock目录落本机仅验证契约，不能跨电脑分发或证明真实OA身份有效。

## 6. 验证与依赖

Node单测验证私有隔离、加密失效、模板白名单、运行状态机、核对规则及输入恶意情况。Electron集成测试验证真正页面和Windows加密，不用纯函数模拟代替。正常链路必须产出正确文件，不能靠全部拒绝通过。每次测试用独立临时数据目录和合成密码，原企业凭据不读取。

首轮无需真实模型/OA、无需付费服务、无需更换现有提供方。真实模型效果和真实企业准入保持待验收；未来选择API能力时优先复用已获准连接，不为简化强制所有操作走截图。
