# 使用指南

## 启动

在项目根目录运行 `npm start`。若尚未安装依赖，运行 `npm install`；本机已有Electron时可设置 `YUANYU_ELECTRON_PATH` 为其exe，避免重复下载。

正常启动会占用固定本机端口15331/15332（采购/仓储）与15333（交互浏览器演示），以保持来源绑定；端口占用时明确启动失败，不改绑到其他网站。`npm run test:desktop`始终用随机端口和全新临时数据目录，不修改正常工作区。

## 兼容的Mock测试闭环

以下为无productClient的开发控制器/桌面smoke验证流程；正常首页使用后文个人注册入口。

1. 保持“Mock公司 / alice”身份。系统与账号中为采购和仓储分别录入合成账号 `demo` / `demo123`，选择本机保存。不要录入真实企业密码。
2. 在工作台输入“整理2026年10月采购月报”，核对月份和预设流程说明，确认执行。
3. 浏览器真正打开两个Mock网页，完成登录、筛选与表格读取。工作台显示实际步骤；完成后打开CSV及来源说明。
4. 核对结果，选择保存为“采购月报”，置顶。首页从卡片启动，改为2026-09，验证结果不同。
5. 在我的工作流发布到Mock公司；切到bob查看公司目录并导入。bob需保存自己的合成凭据才能运行，不能借用alice登录。
6. outsider属于另一Mock公司，不能查看或导入前公司模板。发布者可撤回目录项，已添加的个人副本独立存在。

## 数据与能力边界

主界面身份切换仅用于合成验证，不是真实企业登录。首轮任务识别和页面步骤是预设配方，不代表任意流程的自主学习能力。公司目录仅本机Mock，不具备跨电脑共享和真实OA撤权能力。

“已加密保存”表示凭据已保存在本机，不代表账号已经登录验证；实际执行会验证登录结果。交互浏览器支持用户接管登录/MFA；固定采购配方不包含任意企业登录适配。当前采购仅支持两个演示月份，文字与月份参数冲突时需要先统一。

产物与加密凭据保存到本机用户目录；删除系统凭据后后续运行不能从库取用，已有登录会话须另外清理。关闭程序会关闭本轮受控业务浏览器；重开后需重新登录，不持久化浏览器cookie。

## 测试

`npm test`验证核心与规则，`npm run test:desktop`验证真实Electron、OS加密及页面闭环，`npm run check`验证语法和文档链接。桌面测试使用全新的临时目录、随机端口及合成账号，不复用日常工作区。截图写到忽略的`output/screenshots`；临时测试目录不作为用户日常数据使用。

## 对话工作区与工作流版本

界面采用Codex式中性灰对话布局：左侧新任务、历史、工作流与设置；中间对话；输入固定在底部。执行步骤默认折叠，文件保留为可打开的产物卡。设置中选择深色、浅色或跟随系统，主题按钮也可切换；只将主题偏好写入localStorage。

工作流可以编辑名称、说明和默认月份，停用或启用，查看历史并恢复。每次内容/状态变化创建新修订；恢复历史内容也创建新版本，不删除后续记录。旧的公司发布自动撤回，重新试运行后再发布。当前编辑器仍基于固定采购配方，不能编辑任意浏览器步骤或声称已经学会所有业务。

## 受控HTTPS站点

系统与账号中添加站点名称、HTTPS入口和允许的精确页面路径，之后可以编辑或移除。路径不支持通配，网址不能包含内嵌账号、查询参数或片段。源改变后旧凭据不能自动填入新来源。

打开独立浏览器后由用户操作登录和MFA；“观察”只返回有限的页面文字和元素引用，隐藏字段、输入值和敏感URL参数不回传；“接管/继续”切换人工与受控模式。它不表示登录一定成功，需要看当前页面。自动化中的元素ref在页面变化后失效，必须重新观察。

自定义站点当前以手动登录和页面观察为主；可信自动填充已在独立合成站点验证，尚未自动识别任意登录表单。页面导航和XHR受配置路径限制；同来源静态资源可以加载，跨来源CDN、SSO、子框架及复杂API依赖仍需适配。普通工具不会自动点击业务提交。注册站点不会将它变成采购月报配方的数据来源。

## 本机模型配置

在设置点击“打开本机配置”，编辑仓库外的`models/<company>/<user>/model.local.json`。默认disabled，不联网、不自动读取旧项目密钥。

```json
{
  "schemaVersion": 1,
  "enabled": false,
  "baseUrl": "https://YOUR-COMPATIBLE-PROVIDER/v1",
  "model": "YOUR-MODEL",
  "apiKeyFile": "用户自己指定的绝对路径密钥文本文件",
  "dataScope": "task_text"
}
```

填入自己已获准使用的兼容接口、模型和文件路径，启用并保存，刷新状态。密钥文本文件只放密钥值，不能放JSON或写入仓库。该外部文本文件不自动加密；按企业策略管理其访问权限。业务系统账号则单独使用OS加密库。

“已配置”仅验证本机配置格式，不代表连接或智能水平已验收。选择“模型规划”并逐次同意后，只发送当前任务文本和公开固定配方；计划仍需确认才执行。402/401/超时明确报错，不自动切提供方或重试。界面不展示密钥，主进程仅在实际调用时读取。

如需模型理解网页，将配置中`dataScope`明确改为`selected_pages`。工作台选择“模型浏览器任务”，只选本次需要的1—3个HTTPS站点，分别勾选发送任务文本、发送所选页面。核对计划再执行；登录/MFA由你在独立窗口完成后点击“继续任务”。页面及工具结果是外部不可信材料，普通工具不能审批、付款或提交业务修改。配置或身份在执行期间变化会停止；取消不自动重试。

模型配置及文本同意不会自动授予网页发送权限；默认`task_text`仅用于固定采购规划。真实模型连接及质量尚未进行外部验收。

## 通用浏览器演示与个人工作流

1. 新任务中选择“合成模型 · 浏览器”，使用默认内建交互站点，输入“读取2026-09合成记录”，查看并确认执行。
2. 待任务提示接管后，在独立合成窗口输入`demo` / `interactive123`，下一页输入合成验证码`246810`。这些仅为演示数据。
3. 回工作台点击“继续任务”。工具会真实筛选页面；结果应显示`SYN-091`、`9087`分。2026-10为`SYN-101`、`12345`分。此演示使用确定性驱动，不代表真实模型智能。
4. 完成后点击“保存为浏览器工作流”，命名并置顶；在首页或工作流页重跑。重放以当前页面唯一角色/名称定位并重新读取，登录过期会再次请你接管。

通用任务和采购任务分别保存。浏览器工作流保留目标、站点版本及有限只读步骤/查询条件；不带密码、原始页面或结果记录，只供本人使用。站点origin或revision变化后旧任务/工作流会拒绝继续，需重新确认来源并创建流程。重启后历史任务保留，由用户显式恢复；只读步骤从新观察重跑，不承诺任意业务断点续跑。重放完成提示仅说明步骤执行成功，仍需核对当前网页结果。

## 开发包、备份与企业接入

`npm run pack`生成未签名便携开发目录，`output/portable-latest.json`给出最新路径；其中`electron.exe`可以启动。应用文件有SHA256清单，包中不包含用户目录、模型密钥或运行数据，不等于已签名生产安装包。

备份/恢复目前提供可信开发接口，要求先静止工作区；恢复只能写全新目录，校验文件后迁移产物引用，不覆盖原数据、不备份浏览器缓存和外部模型密钥。凭据仍绑定原OS用户，换机器或用户后可能需要重新录入。尚未向普通成员开放“导出所有本机身份”的按钮。

OIDC成员验证、HTTP公司模板共享和写入确认端口已有合成验证，正式工作区仍使用Mock身份。真实OA登录、服务端模板授权与具体业务回执必须另外接入；目录适配器存在不表示已经登录钉钉。

## 个人免费版与企业入口

新安装运行`npm start`会显示个人/企业入口，并自动启动仅本机可访问的合成账号服务（15334端口）；界面明确标记合成演示，注册/密码验证/额度记账是真实本机链路，模型响应是合成的。企业联系微信：**wsltest**，可直接复制；没有自动开通生产企业权限。个人版中公司流程可以查看公开示例，不能导入、执行或发布。

选择个人版→注册邮箱/名称/密码→在设置输入页面显示的合成校验码→使用工作台。生产服务不会返回合成验证码：需邮箱验证适配器，或开发者核实后通过本机运营CLI验证账号。账户验证不代表企业成员身份。

默认每账号每天20次模型请求、每月10万Token；一次多步骤任务可能调用多次。额度按北京时间每日/每月零点更新。界面显示已用、预留与剩余额度，开发者可调整。超时或缺失用量的请求会保留预留，需核查；不自动重试。自己的API仍需注册，但费用由本人的提供方计收，不扣开发者推广额度。

设置→模型，可选择服务端公开的推广模型，或“自己的API”。可保存多个DeepSeek、GLM、千问、Kimi、火山方舟和自定义Chat Completions兼容服务配置，输入提供方对应的模型ID。原生Anthropic/Gemini协议尚未适配，需兼容网关。API key只在提交时进入可信主进程并OS加密，表单立即清空；选择/保存不联网。“测试当前模型连接”需二次确认，可能产生一次费用或额度消耗。

## 接入开发者购买的API

真实推广需在你控制的服务器部署账号/额度/推理服务，并以HTTPS提供给桌面客户端。**开发者API key仅放服务器**，不要把真实服务密钥随便携包分发。仓库内不存账号库或密钥。

在服务器仓库外创建配置（路径按部署环境调整）：

```json
{
  "dataDir": "D:/YuanyuService/data",
  "host": "127.0.0.1",
  "port": 15334,
  "demo": false,
  "monthlyTokens": 100000,
  "dailyRequests": 20,
  "globalMonthlyTokens": 1000000,
  "developer": {"name": "开发者", "contactType": "wechat", "contact": "wsltest"},
  "providers": [{
    "id": "my-promotion-model",
    "label": "免费推广模型",
    "baseUrl": "https://YOUR-COMPATIBLE-PROVIDER/v1",
    "model": "YOUR-MODEL-ID",
    "apiKeyFile": "D:/YuanyuService/secrets/provider-key.txt"
  }]
}
```

`globalMonthlyTokens`的100万仅为配置示例，并未获准实际消耗；应按你购买的预算调整。Token上限限制调用量，不等于固定人民币金额，提供方可能对模型/缓存等采用不同价格。真实模式未显式设置总预算时拒绝推广调用。

PowerShell设置`$env:YUANYU_PROMOTION_CONFIG='D:/YuanyuService/service.json'`后运行`npm run service`。启动/状态查询不调用模型。将反向代理HTTPS入口指向该服务，桌面用户目录的`product.local.json`改为：

```json
{"schemaVersion":1,"serviceUrl":"https://YOUR-SERVICE-HOST","allowLocalDemo":false,"autoStartLocalDemo":false}
```

重新启动后才接入新服务。自带本机合成服务只用于开发；生产不能让个人客户端自行决定账号额度。既有product.local.json不会被覆盖，旧配置若要自动开本机演示需手工添加autoStartLocalDemo:true。若单独运行`npm run service`，客户端同样设置autoStartLocalDemo:false以避免端口冲突。

真实服务尚未部署，也未配置购买的API、邮件发送或真实模型盲测；本轮没有实际付费调用。

## 浏览器工作流参数与合成业务确认

个人浏览器工作流可以编辑名称，把原任务中已经成功执行的查询/选择步骤设为参数；每次编辑产生新修订。运行前确认参数，只替换值，不改变站点、控件或业务操作。旧版本暂停任务不能借新版本继续，需重新运行。此功能并不自动记录用户在接管窗口中的任意点击，也不等于任意流程学习。

设置→合成业务写入验证：选择演示月份，输入不含凭据的核对备注→预览→核对月份、备注和有效期→确认保存。它实际写入本机合成源的草稿并生成回执；没有真实企业提交。未知回执仅可“核对回执”，不会自动重试。备份会同时包含合成源及其审批账本。

现有工作区备份不带注册服务数据库、加密账号会话、多模型API配置、外部密钥或浏览器缓存。恢复后需要登录及重新配置自己的模型；运营服务器数据库需另行静止后备份，不能用桌面备份替代。

## 运营者管理账号与额度

在服务器设置同一个`YUANYU_PROMOTION_CONFIG`后，使用以下本机命令。CLI直接操作本机账号数据库，不开放HTTP管理接口，也不读取API密钥：

```powershell
npm run service:admin -- list
npm run service:admin -- verify user@example.com
npm run service:admin -- disable user@example.com
npm run service:admin -- enable user@example.com
npm run service:admin -- revoke user@example.com
npm run service:admin -- quota 100000 20
npm run service:admin -- budget 1000000
```

verify须由你在核实注册者后执行。disable会停用账号并撤销已有会话；enable不会恢复旧会话，用户必须重新登录。quota调整全体个人账号后续请求的额度，budget调整全局月Token预算，均不会清空已用或预留金额。命令中的100万同样仅是示例，运行budget会授权该上限，需自行按购买预算填写。服务配置显式指定的额度会在重新启动服务时重新应用，长期变更应同步配置文件。

## 教我做一次：受控人工示范

新任务输入框旁点击“教我做一次”，填写目标并确认站点。无需配置模型，不扣模型请求次数或Token额度。

1. 首次体验选“本机合成演示站点”，填写“按月份筛选合成记录并核对”。
2. 当前页面需要登录时，点击“接管登录或验证”，在独立窗口使用demo / interactive123，合成MFA为246810。返回工作台点击“继续示范”。登录过程不记录。
3. 在“选择当前页面的只读控件”中选择月份控件，筛选条件设为2026-09，点击“执行并记录”；再次选择“筛选合成记录”并执行。
4. 展开“查看当前页面文字”，核对SYN-091和9087分，再点击“已核对，完成示范”并确认。若页面在确认时发生变化，会显示新结果，要求再次核对。
5. 保存为个人浏览器工作流。可在编辑器把成功月份选择步骤声明为参数，下一次传入2026-10重新执行；会话关闭后需要重新登录。

示范期间其他任务和站点/模型配置暂时不能执行。取消、退出和账号切换会关闭当前示范会话。重启后示范标为中断，原记录保留，可直接重新开始，不会将它交给模型继续。

这项功能只记录工作台内明确选择的安全只读操作，不直接捕获你在网页上的任意点击。自定义HTTPS站点仍受既有来源/路径和只读操作策略限制；没有点击白名单的按钮不会自动获得权限。任务与Skill不会保存页面正文、动态引用、密码或验证码。
